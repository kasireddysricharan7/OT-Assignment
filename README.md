# OT Assignment

This repository contains the Python implementations and outputs for the Optimization Techniques assignment.

## Methods Implemented

### 1. Big-M Simplex Method

The Big-M Simplex Method is used to solve the given Linear Programming Problem (LPP).

**Files:**
- `Big-M.py` - Python implementation of the Big-M Simplex Method
- `Big-M_output.txt` - Output of the program

### 2. Vogel's Approximation Method (VAM)

Vogel's Approximation Method is used to obtain the initial basic feasible solution for the transportation problem.

### 3. MODI Method

The Modified Distribution (MODI) Method is applied to the initial solution obtained using VAM to determine the optimal transportation plan.

**Files:**
- `Transportation_cost.py` - Python implementation of VAM and MODI
- `vam_modi_output.txt` - Output of the program
